## Exact public read routes

GET /api/poi/status, GET /api/poi/categories, GET /api/poi/bbox, GET /api/poi/attribution and OPTIONS on these exact unescaped paths only. Anonymous other methods/unknown/encoded paths stay behind default-deny auth; authenticated unsupported methods rejected 405. No changes to existing protected API or street tile policy. Public reads do not verify/forward authorization or cookies, and bypass activity working counter. No new per-user telemetry or viewport logs. Originless CLI GET permitted; browser CORS only https://gps.themauris.org, no credentials or wildcard, OPTIONS requires that origin/requested GET, only optional If-None-Match header. No preview origin. CORS is browser policy, not access control; public CLI requests are intentional. All valid requests share independent global 8/s burst 16, four nonqueued HTTP admissions, no per-IP state; reader also has its existing four-slot admission. Query deadline 1s, response write deadline 3s when supported by HTTP server. No cache store beyond OS cache; successful available GET responses public max-age=60 with strong SHA256 of actual encoded representation ETag, weak If-None-Match comparison supported. Response computed before conditional check, never 304 for unavailable/errors. Attribution static text independently cacheable even when data disabled. Unavailable status/categories 200 no-store; bbox 503. 400 invalid input, 403 origin/preflight, 429 admission/rate (Retry-After:1), 503 unavailable/timeout/read failure. Error JSON no-store, no private paths.

Status includes version 1, available, coverage, dataset_version (release/mapping/full payload hash or null), snapshot_at (release UTC timestamp), registry_revision, category_counts, sources, attribution_url, notice. Categories includes version, revision, dataset_version, categories object with label/icon/color/available/native_category, attribution_url. Seven terrestrial and four marine categories; marine known but unavailable. GPS Map owns static native graphics, not dynamic registry synchronization.

Example GET /api/poi/bbox?bbox=-122.43,37.77,-122.39,37.81&category=coffee&category=restaurant&limit=200. Exactly one bbox, 1–4 unique known categories and optional integer limit 1–500 (default 200); raw query <=1024 bytes, strict decimal finite ordered inclusive WGS84 bounds, <=0.5 degree spans and <=0.125 square degree area; no unknown/duplicate scalar/malformed query. Categories normalized in lexical order. Bbox responses: version, dataset_version, registry_revision, categories, unavailable_categories, records (each {provider_categories:[key],waypoint:{id,lat,lon,name,category,notes,created}}), truncated, sources, attribution_url, notice. Native known category preserved. Empty available result vs unavailable categories explicitly distinct. Stable ID order; full JSON response <=512 KiB; wrapper overhead accounted per complete record, truncate prefix. No pagination, bulk dump, live upstream or search/write endpoints.

Attribution exact path returns embedded plain text, full CDLA/Apache/CC0 and Foursquare NOTICE, prominent upstream attribution and change date 2026-11-27. Public developer documentation should link this route. No rights assumption for marine. Owner operational publication approval and real tunnel verification still required.
