**Current implementation:** The separate `cmd/nauticaltilemanager` now accepts **additional geographic rectangles and zoom levels in the *same* existing manager-marked NOAA directory**, preserving existing PNGs and retaining the original v1 marker. It calculates overlaps and missing paths, enforcing `existing files + new files <= -max-tiles` before any write; `-max-bytes` checks the full existing byte count before acquisition and the real size of every new PNG before saving. Dry-run with `-dir` prints inventory without disk writes or NOAA network access. Only explicit `-download` acquires NOAA WMS PNGs; the read-only browser handler and layer-native z16 limit are unchanged.
